# StatusTag 状态标签

事项的状态。全库只有五种状态，含义固定：

| status | 文字 | 颜色 | 含义 |
|---|---|---|---|
| `done` | 已完成 | 绿 | 已验收、已关闭 |
| `doing` | 进行中 | 蓝 | 正常推进 |
| `risk` | 有风险 | 橙 | 可能延期或超预算，需关注 |
| `blocked` | 受阻 | 红 | 已停滞，需要外部协调 |
| `todo` | 未开始 | 灰 | 尚未启动 |

- `children` 可改文字（如「已上线」），但颜色仍由 `status` 决定——不要为文字另选颜色。
